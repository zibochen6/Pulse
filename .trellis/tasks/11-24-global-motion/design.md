# Design

- When AppKit is closing, explicit status clicks toggle a pending open intent. Consume it on the main run loop after didClose cleanup. Clear it on Settings, exit or forced dismissal. The hover controller cannot itself reopen the panel. Suspend geometry reconciliation only while hover dismissal is held and immediately resample on release.
- Coalesce and round height updates. Use the current task source and staged update state in the sizing decision. AppKit owns the window geometry and native entrance/exit. A single live hosting view forwards the current locale, appearance, motion, paper and focus environment. Only route changes initiate a 140 ms opacity transition. Sample a running fade's presentation value before replacing it. Keep only the incoming content and the native field editor for the active route.
- Share immediate pressed and keyboard feedback, 90 ms release, 120 ms hover, 140 ms semantic fades, 180 ms completion feedback and 200 ms zero-bounce local motion. Never delay state changes for an animation. A brief pending action retains its previous glyph, then shows a busy glyph after 150 ms if still pending. Reduce Motion skips custom animation, including rotating indicators and native drag return.
- Use stable row IDs and lazy task stacks, keep composer anchor and focus requests current, avoid publishing measurements used only by drag, and change a drag preview only when its target changes. Use the actual window's display link from macOS 14 and elapsed-time fallback on 13. Stop at bounds or when leaving the edge, dismissing or cancelling. Preview only while input is active and settle towards the confirmed order.
- Runtime dependencies and persisted state keep their existing interfaces. Use isolated data for all test windows and traces. Existing DemoFixture and test-host isolation are the basis for profiling. Status labels communicate only the corresponding real phase.

## Clipboard and task entry

- Quick Copy has a dedicated popover route. Write a single string representation using AppKit, and publish success only on successful write. Retain the fixed feedback area, use the most recent copy action and cancel older timers. Inject clipboard and storage dependencies for the isolated host. Store UUID, name and exact body in an atomically written local JSON document. Preserve a draft and its previous stored result on write failure.
- The explicit Add action and its native text entry share one persistent composer below the scroll view. Establish active AppKit editor ownership in the Add handling path before animation or scroll work. Confirm ownership with the active editor, not the Boolean returned by the window alone. Defer any SwiftUI-facing publication that must occur outside the layout update. Revoke old focus requests on collapse, source change or removal. Native composition owns first responder, selection and provisional text until confirmed.
- Remove view-mount appearance tasks from input surfaces and the Home title. Limit route fades to route changes and semantic feedback to the affected label or icon. Changes still comply with the original 5 ms/s active-interval target. Measure against the current release with consistent display and scene fixtures.
