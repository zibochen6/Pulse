# 30-minute focus timer

From the Pulse Home toolbar, start a fixed 30-minute focus session with one click. The toolbar shows an active state and allows cancellation. The timer continues with the popover closed and plays one chime at completion, with no visual notification or countdown in the macOS menu bar.

Acceptance: one session at a time; cancellation is silent; reopening the popover preserves state; sleep counts toward elapsed time and an overdue session chimes once on wake. Explicit quit or restart ends the session. Automatic update restarts wait for the session to end.
