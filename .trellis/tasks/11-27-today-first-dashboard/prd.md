# Today-first Pulse dashboard

The user approved the whole plan and creation of this task. Pulse should let a macOS user decide and do the next action without switching apps. The public baseline is 0.1.30. Today execution has priority, with concise AI status and current-only data.

- Home immediately exposes editable paired Today tasks or the selected native list. Keep date and the recording, focus, copy and Settings actions. Preserve native first keystroke, IME, drafts, tags, undo and Obsidian sync.
- Keep unfinished rows in source order. Fold confirmed completed items by default, including in local lists. Waiting rows remain accessible with clear sync state. Show meaningful counts, fixed Add access, compact short lists and a scrollable task area.
- A compact Home footer shows the important current AI status, then opens an overview of enabled services. Show explicit provider, windows, remaining amount, reset, update and error states. Details include independent quota bars and relevant balances. User can retry or manage the correct provider.
- Keep Quick Copy confirmation and stable ranking, focus countdown and stop, and the resolvable recording result. Preserve native popup input and hover, with reduced motion and transparent material support.
- Demonstrate the core paths on isolated test data in both languages and appearances. Compare opening, editing, scroll and route hitches with 0.1.30 on the same Mac. Release after meeting the acceptance criteria.
