# Pulse 的 Apex 任务界面设计

## 信息层级

Pulse 仍是 360×510 的 macOS 菜单栏弹窗。Home 页眉保留 Pulse 标识、紧凑可点击的 Codex 状态和设置入口。其余主要空间交给 Tasks：先看当前列的待办，再看卡片归属；AI 额度详情仍由现有 Usage 页面承载。Pulse 不复刻 Apex Dashboard 的多栏布局、banner 或卡片装饰。

## 任务区

1. Tasks 标题旁提供手动刷新动作。下面是按 Dashboard `columns` 顺序生成的水平可滚动页签；只把**列**做页签。备忘类卡片仍在其原列内。
2. 选中列内以卡片标题分组，卡片中的任务按文件顺序形成紧凑行。未完成任务用更醒目的视觉样式呈现，已完成任务弱化显示；两者均不改变源文件顺序。长文本换行，列表纵向滚动。
3. 空列显示简短“此列暂无任务”；未配置、文件缺失和读取失败显示对应状态与“选择文件／重试”入口，不造示例任务。任务复选框仅作为状态图形，不接受勾选。
4. 每次打开弹窗读取一次；用户也可手动刷新。文件在弹窗持续打开期间被外部修改时，界面可能暂时显示旧快照，直到下一次刷新。本版没有文件监听或后台轮询。

当前样本没有任务日期字段。“快速看到今天要做什么”在首版指快速查看用户原有列中的任务，不代表 Pulse 能识别今日到期任务，也不提供自动的 Today 筛选。

## 打开原文件

点击任务行只请求 Obsidian 打开**对应 Markdown 文件**。使用官方 [`obsidian://open?path=...` 形式](https://help.obsidian.md/Extending%2BObsidian/Obsidian%2BURI)，对绝对路径做 URI 编码，并检查系统是否能处理该 URI。`lineNumber` 不拼进 URI；首版不承诺跳到具体任务行。Obsidian 未安装或打开失败时提供简短可操作提示，不更改任务状态。

## 可访问性与后续扩展

页签、刷新和任务行有明确的键盘焦点与辅助功能标签；任务行标签包含完成状态、文本和卡片归属。浅色／深色模式使用系统语义颜色。未来若要勾选或新增任务，应在完成独立的写回安全设计后再加入交互控件。
