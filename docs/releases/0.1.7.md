# Pulse 0.1.7 (build 11)

## Changes

- **Completed tasks stay where they are.** Finishing a task now just dims and
  strikes the row through, in place. The separate **Completed** heading with its
  count and collapse chevron is gone, so the list keeps one consistent shape no
  matter how many tasks are done. Open and completed tasks share a single list
  in saved order, and un-completing a task restores it exactly where it already
  was.
- **The panel fits a stable 360 × 380 surface.** The header is now a light
  toolbar — the Pulse identity on the leading edge, Settings on the trailing
  edge — with a separate compact quota strip directly below it. The panel no
  longer changes size as content loads, saves or expands.
- **The quota strip is compact and self-wrapping.** Each provider shows its name
  above its current value, so long amounts and multiple Codex windows stay
  readable without clipping decimals or overlapping Settings. Money keeps its
  own currency and is never mixed into a percentage.
- **The task list ends with a left-aligned `+ Add task` row** that expands quick
  entry in place, replacing the floating centred button. The tag row's `+` has a
  tooltip and a proper accessibility label.
- **Tag selection is clearer.** The selected pill slides its accent plate between
  tabs instead of cross-fading, and hover, press and keyboard focus are each
  visible and distinct. Keyboard focus draws a shape-matched soft outline rather
  than the square system ring, and Tab / Return / Space work as expected.
- **Motion is unified and deliberately restrained.** Hover and press feedback sit
  in the 90–140 ms band, tab and page changes in 160–200 ms, and the composer
  expands in about 200 ms, each with its own curve from a single set of design
  tokens. Page entry moves a few points in the direction of travel and fades in.
  Every animation respects Reduce Motion: with it enabled, offsets, springs and
  scaling are dropped and nothing moves.
- **The pending completion no longer changes the row.** The spinner overlays the
  check control instead of replacing it, so the row keeps its geometry and the
  save reads as one continuous acknowledgement. The API key field is now covered
  by the same protection that keeps a task draft open, so the panel no longer
  dismisses while you are typing credentials.

Every new animation respects Reduce Motion; with it enabled, nothing moves and
behaves exactly as before. No storage schema change is introduced: task data,
preferences and Keychain items remain in place, and existing files need no
migration.

## Installation and updates

Download [Pulse 0.1.7](https://github.com/zibochen6/Pulse/releases/tag/v0.1.7).
Supports macOS 13+, Apple Silicon (`arm64`) and Intel (`x86_64`). Assets:
`Pulse-0.1.7.dmg`, `Pulse-0.1.7.dmg.sha256`, `Pulse-0.1.7.zip` and
`Pulse-0.1.7.zip.sha256`. DMG, updater ZIP and local installation use the same
signed application.

Existing Pulse 0.1.3 and later installations can discover this version through
Settings → Updates or automatic checks. For manual installation, quit Pulse,
open the DMG and drag Pulse into Applications before launching it again.

This remains an Apple Development-signed preview, not Developer ID-signed or
notarized, using the existing preview distribution channel.

## Validation and limits

- 209 automated tests passed using isolated task stores, covering the fixed
  360 × 380 surface ratio, the quota strip below the toolbar, the task list
  fitting the height the popover actually leaves it, a pending completion not
  moving its row, and the tag selection plate really being painted in an
  off-window render. Completed tasks are covered by a case asserting they keep
  their stored position and completion flag.
- Strict formatting and diff checks passed. Aqua and Dark Aqua renders of every
  task surface state were generated and inspected, at both a stress height and
  the real popover region, and the before/after comparison set was reviewed.
- The release pipeline verifies tests, universal build, signing, mounted DMG,
  extracted ZIP, checksums, installed application and published asset digests.
- Live desktop checks of the real menu bar popover, hover and focus feedback,
  page transitions, completion flow and Reduce Motion on a real display remain
  for manual verification. The tests exercise these surfaces off-window, which
  is not the same as using them with a mouse and a real screen.
