# Pulse 0.1.24 (build 28)

- In Settings → General → Appearance, adjust one Background transparency slider for the menu bar panel and Settings. It defaults to 25%, and 0% restores a solid background.
- Pulse uses macOS materials and respects Reduce Transparency while keeping your saved choice.
- 在「设置 → 通用 → 外观」里用同一个滑杆调整菜单栏弹窗和设置窗口的背景透明度。默认 25%，调到 0% 可恢复实底。
- 背景采用 macOS 原生毛玻璃。系统开启「减少透明度」时会显示实底，保留此前选好的数值。
