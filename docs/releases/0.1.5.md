# Pulse 0.1.5 (build 9)

## Changes

- Keep the task list simple: a centered **+** follows all items and the Completed
  group. Click to expand inline entry; a successful save clears and collapses it.
- Collapse with Esc or the close control without losing your draft. Separate
  drafts and expansion state survive list switches and popover closure. Failed
  saves preserve input for retry; late replies cannot hide reopened input.
- Refine the task editor with Cancel / Edit task / Save in the header, a spacious
  multiline content area, compact list and daily-repeat rows, and Delete below.
- Create new tags from the list menu only when needed. The tab bar still creates
  empty independent tags directly and opens entry in the new list.
- Improve native focus and scrolling when entry appears, Escape handling across
  controls, and late text-field callbacks so saved task/tag input stays cleared.

Existing single-list membership, daily repeat, completed grouping and the last
20 task deletion undos remain available. No storage schema change is introduced;
task data, preferences and Keychain items remain in place.

## Installation and updates

Download [Pulse 0.1.5](https://github.com/zibochen6/Pulse/releases/tag/v0.1.5).
Supports macOS 13+, Apple Silicon (`arm64`) and Intel (`x86_64`). Assets:
`Pulse-0.1.5.dmg`, `Pulse-0.1.5.dmg.sha256`, `Pulse-0.1.5.zip` and
`Pulse-0.1.5.zip.sha256`. DMG, updater ZIP and local installation use the same
signed application.

Existing Pulse 0.1.3 and later installations can discover this version through
Settings → Updates or automatic checks. For manual installation, quit Pulse,
open the DMG and drag Pulse into Applications before launching it again.

This remains an Apple Development-signed preview, not Developer ID-signed or
notarized, using the existing preview distribution channel.

## Validation and limits

- 180 automated tests passed using isolated task stores, including native
  field focus, actual scroll movement, draft collapse/retention, stale responses,
  text Undo/Redo, IME command gating and late end-edit callbacks.
- Strict formatting and independent review passed. Twenty-eight Aqua/Dark Aqua
  state renders were generated; representative list, editor and tag states
  were inspected without clipping or overlap.
- The release pipeline verifies tests, universal build, signing, mounted DMG,
  extracted ZIP, checksums, installed application and published asset digests.
- Actual desktop mouse and Chinese input-method candidate delivery remain
  unverified because native automation timed out. Automated native-field tests
  do not certify that live interaction coverage.
