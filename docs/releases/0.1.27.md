# Pulse 0.1.27 (build 31)

- Open **Quick Copy** from Home to save named prompts and commands. Select a
  name to copy the full text, including line breaks. The row confirms the copy.
- Add a task and start typing immediately in local Todo or paired Obsidian Today.
  Search by title within the current list.
- The menu bar panel and Settings use consistent feedback for navigation, hover,
  and completion. Motion follows the Mac's Reduce Motion setting.

## 中文

- 从首页打开「快速复制」，给常用提示词和指令命名。点击名称即可原样复制全文，条目会显示「已复制」。
- 修复本地待办和 Obsidian 今日待办点「＋」后偶发丢首键的问题。两种待办均支持按标题搜索。
- 统一菜单栏弹窗和设置的切页、悬停及完成反馈，并跟随 macOS 的「减少动态效果」设置。
