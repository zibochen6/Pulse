# Pulse 0.1.10 (build 14)

## 30-minute focus timer

Open Pulse and select **Start 30 min focus** in the Home toolbar. The timer
continues after you close the panel and plays a chime when the session ends.
Select **Focusing · Cancel** to stop it early. The menu bar continues to show
Codex usage. Automatic update restarts wait for the focus session to end.

## Download or update

If Pulse is already installed, open **Settings → Updates → Check for updates**.
The [Pulse 0.1.10 release](https://github.com/zibochen6/Pulse/releases/tag/v0.1.10)
also includes a DMG for manual installation. This Apple Development-signed
preview supports macOS 13 and later on Apple Silicon and Intel.
