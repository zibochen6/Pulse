# Pulse 0.1.9 (build 13)

## Fixed: deleting a list no longer mixes its tasks into Todo

Deleting a custom tag now deletes that complete list and its tasks together.
The confirmation names the list, shows the task count and explains Undo before
the destructive action. Default Todo and all other lists remain unchanged.

One **Undo** restores the original tag and all its tasks, including their order,
completion and daily-repeat state. Empty lists can also be restored. The Undo
control is available on Home and in tag management, including Settings. Task
and list deletions share the latest 20 operations during the current app run;
quitting Pulse clears this in-memory history.

Unfinished input blocks deletion of its affected list. This also covers editing
a task while changing its destination to a different list. Storage captures the
complete deletion in one transaction; restoration preserves unrelated changes
and refuses conflicting task IDs or list names rather than overwriting them.

Existing tasks moved into Todo by earlier versions remain unchanged. The old
deletion did not keep their former tag associations, so this update does not
guess which existing tasks belonged to a removed list. Storage stays schema 1.

## Installation and verification

Download [Pulse 0.1.9](https://github.com/zibochen6/Pulse/releases/tag/v0.1.9).
macOS 13+, Apple Silicon and Intel. The manual DMG and automatic-update ZIP use
the same Apple Development-signed preview app, with SHA-256 checksum files.
This continues the existing preview channel without Developer ID notarization.

259 automated tests passed, with two opt-in demo tests skipped as expected;
nine Chinese-focused checks also passed. Regression coverage includes whole-list deletion/restore, interleaved task
positions, empty lists, mixed Undo ordering, conflicts, write/verification
failure recovery, draft protection and both Undo surfaces. The release pipeline
verifies universal architecture, signing, packaged payloads, installed app and
published asset digests. No test uses the real task file.
