# Pulse 0.1.2 (build 6)

## Changes

- Add optional DeepSeek API account balance monitoring through the official
  service. Home shows the reported CNY or USD total; when both are available,
  Home prefers CNY and Usage lists each currency separately. Balances are never
  converted or summed, and zero or negative reported totals remain valid.
- Add an independent DeepSeek API-key form in Settings → Providers with save,
  replace and remove actions. Keys are stored only in macOS Keychain. Credential
  changes immediately clear the previous account reading, start a fresh request
  and reject late replies from the old account, including for 88VIP.
- Use the actual official DeepSeek whale mark across Home, Usage and Settings,
  preserving the original vector details and blue color.
- Move header provider controls toward the leading edge. When a single row
  cannot fit, complete indicators wrap into leading-aligned rows without
  truncating amount digits or covering Settings. The popover remains 360 × 510.
- Refresh DeepSeek at launch, every ten minutes, on popover open for readings
  older than 60 seconds, and after manual refresh or credential changes.
  Requests time out; missing keys and failed refreshes show explicit guidance
  instead of displaying an old amount as current. The system menu bar continues
  to show Codex only.
- Include the shared UI controls introduced since 0.1.1: consistent task filters,
  row and icon button feedback, inline task error banners, spacing and keyboard
  focus treatment. Hover and press transitions respect Reduce Motion.

## Installation

Download `Pulse-0.1.2.dmg` and its `.sha256` file from the
[GitHub release](https://github.com/zibochen6/Pulse/releases/tag/v0.1.2).
The app supports macOS 13+, Apple Silicon (`arm64`) and Intel (`x86_64`).

Quit the previous Pulse instance, open the DMG, drag Pulse into Applications
and launch the installed app. Replacing the bundle preserves existing task
storage, settings and Keychain items. Do not run an old development build
simultaneously. Configure DeepSeek through Settings → Providers after launch.

In the download folder, verify the checksum with:

```sh
shasum -a 256 -c Pulse-0.1.2.dmg.sha256
```

This preview uses Apple Development signing, **not Developer ID signing or
notarization**. macOS may block first launch. If you trust the build, follow
[Apple's app-opening guidance](https://support.apple.com/102445) using the
available Open Anyway option; do not disable Gatekeeper. This release is not
a claim of fresh-machine or notarized-distribution acceptance.

## Validation

- Full suite: 194 collected, 192 passed, 2 existing off-window task accessibility
  checks skipped, 0 failed. Automated tests use synthetic provider responses,
  isolated credential stores and temporary task files rather than real accounts.
- Provider and credential regressions cover CNY/USD decimals, malformed data,
  service/network/timeout failures, separate Keychain accounts, key replacement
  or removal during a request, and cancellation cleanup.
- Aqua/Dark Aqua renders and actual control-frame measurements cover Home,
  Usage and Settings, complete amounts, whole-control wrapping and oversized
  quota readouts within the existing popover width. Official-icon correction
  passed both focused rendering tests and visual comparison with the reference.
- Debug build/type-check, changed Swift formatting and diff checks passed.
- Signed universal Release build passed for `arm64` and `x86_64`, with macOS 13
  minimum. The read-only mounted DMG passed signature, 0.1.2/build 6 metadata,
  architecture, executable/resource-signature equality and SHA-256 checks.
- Local installation passed signature, version and executable-hash verification;
  one instance runs from `/Applications/Pulse.app`. The previous installed app
  was retained in a recoverable backup without changing task data or credentials.
- Native menu clicks, scrolling, task editing and hover animation are not
  certified by unit/render checks; the two skipped checks require desktop
  accessibility delivery. A direct desktop inspection attempt timed out, so the
  installed-app process checks do not certify live menu interactions.

## Current limits

DeepSeek monitoring covers API account total balances, not a chat subscription,
spending history or token usage. Only the official endpoint is supported;
reseller/custom endpoints, currency conversion and low-balance notifications
are not included. Real authenticated balance verification requires a key entered
through Settings and was not performed by the automated tests.

The supported Apex format and existing task-storage behavior are unchanged.
Pulse is not a general Markdown task engine. External editors can ignore advisory
locks and file coordination, so a short validation-to-write race remains.
Completed tasks stay in their original source and can be restored there, then
refreshed in Pulse. No private Dashboard, settings or credentials were altered
for automated acceptance.
