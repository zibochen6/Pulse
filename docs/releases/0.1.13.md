# Pulse 0.1.13 (build 17)

- Sync the Obsidian Personal Dashboard's Today Tasks card with Pulse. Add, complete, reopen or delete a task in either app. Project tasks removed from Today stay in their original notes.
- Pulse saves edits when Obsidian is closed and sends them when the paired vault opens. You can still use your native Todo and tag lists.
- 在「设置 → 待办」连接知识库，即可双向同步个人看板的「今日待办」。从今日移除项目任务时，原笔记保留；Obsidian 关闭时，操作在本机排队。

## Connect or update

The connection requires the desktop Personal Dashboard plugin v0.6.10 or later. Use **Settings → Tasks → Choose Vault** in Pulse after installing and enabling the compatible plugin.

Open **Settings → Updates → Check for updates** in Pulse, or download the DMG from the [Pulse 0.1.13 release](https://github.com/zibochen6/Pulse/releases/tag/v0.1.13). The Apple Development-signed preview supports macOS 13 and later on Apple Silicon and Intel.
