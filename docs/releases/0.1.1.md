# Pulse 0.1.1 (build 5)

## Changes

- Home displays unfinished tasks only. Completed rows, counts and expansion
  controls are hidden for both built-in and Apex sources. All-completed Apex
  groups are hidden; no tasks are deleted from their source.
- Detached, damaged or duplicate optional Pulse retry comments no longer blank
  the Dashboard. Reading does not modify the original Markdown.
- Creation retries verify that the complete original insertion still exists.
  A leftover comment beside a reformatted, renamed or pre-existing task cannot
  make that task count as a successful new creation. Ambiguous retries refuse
  saving and retain the external file unchanged.
- Fresh saves verify the current exact byte patch separately, preserving
  serialized creation and legitimate edits before the initial save.

## Installation

Download `Pulse-0.1.1.dmg` and its `.sha256` file from the
[GitHub release](https://github.com/zibochen6/Pulse/releases/tag/v0.1.1).
The app supports macOS 13+, Apple Silicon and Intel.

Quit the previous Pulse instance, open the DMG, drag Pulse into Applications
and launch the installed app. Replacing the bundle preserves existing task
storage and settings. Do not run an old development build simultaneously.

In the download folder, verify the checksum with:

```sh
shasum -a 256 -c Pulse-0.1.1.dmg.sha256
```

The preview is Apple Development signed, **not Developer ID signed or
notarized**. macOS may block first launch. If you trust the build, follow
[Apple's app-opening guidance](https://support.apple.com/102445) using the
available Open Anyway option; do not disable Gatekeeper. This release is not
a claim of fresh-machine or notarized-distribution acceptance.

## Validation

- Creation suite: 25 passed, 0 failed. New regressions first reproduced the
  unsafe retry, then passed after the fix. All writes used temporary files.
- Full suite: 180 collected, 178 passed, 2 existing off-window accessibility
  checks skipped, 0 failed.
- Swift formatting and diff checks passed. Universal signed Release build
  succeeded. The DMG is verified with a mounted-bundle signature/version and
  architecture check before publication.
- Native desktop UI inspection timed out. Actual menu clicks, task editing,
  scrolling and hover animation are not certified by unit/render checks.

## Current limits

Only the supported Apex format is recognized; Pulse is not a general Markdown
task engine. External editors can ignore advisory locks and file coordination;
a short validation-to-write race remains. An uncertain retry after changes
inside its destination card can be refused even if its new task survived.
Refresh and inspect the source file before intentionally creating another task.

Old visible `^pulse-UUID` suffixes from earlier builds are not automatically
removed. Newly created tasks use hidden comments. Completed tasks can be
restored in their original source and then refreshed; Home has no completed
task management section. No private Dashboard, settings or credentials were
altered for automated acceptance.
