# Pulse 0.1.23 (build 27)

- The menu bar panel stays open while the pointer is anywhere in the panel's width from the top edge of the panel to the top of the display. Leaving the full area still triggers the usual short delay before automatic dismissal.
- 鼠标在弹窗或弹窗正上方的菜单栏区域移动时，弹窗保持展开。移出整个范围后仍会短暂延迟再自动收起。
