# Pulse 0.1.4 (build 8)

## Changes

- Create empty tags directly from the tab bar's fixed **+** button, without
  creating a placeholder task. Each task belongs to one independent list.
  **Todo** is always available for untagged tasks; there is no aggregate tab.
- Add tasks continuously from the fixed input below the tabs: Enter saves and
  returns focus. Additional options expose list selection, new tags and daily
  repeat. Moving a task switches to its destination and scrolls it into view.
- Delete tasks directly, with **Undo** for the last 20 deletions until Pulse
  quits. Restoration preserves task identity, content, completion/repeat state
  and relative order; a removed original tag falls back to Todo.
- Keep separate quick-entry drafts across lists, Settings and popover closure.
  Guard repeated submissions and late save responses so later input survives.
- Rename/remove tags from their context menus or Settings. Removing a tag asks
  for confirmation and moves its tasks to Todo. Completed tasks have a counted,
  collapsible section; restoring/moving a completed task expands it as needed.
- Reserve space for row actions to avoid text shifting on hover. Improve
  keyboard actions, native text Undo/Redo and text-binding synchronization,
  input focus and hover-close suspension, and Chinese IME marked-text handling.

## Existing task data

The JSON schema remains version 1. A legacy saved tag named Todo merges into
built-in Todo, making previously unreachable untagged tasks visible again.
Legacy multi-tag tasks keep the earliest-created matching tag. Before changing
legacy bytes, Pulse verifies an exact backup at
`~/Library/Application Support/Pulse/tasks.before-single-list.json`.
Normalization retains task IDs, text, order, completion and daily-repeat state;
backup failure leaves the original file unchanged.

## Installation and updates

Download [Pulse 0.1.4](https://github.com/zibochen6/Pulse/releases/tag/v0.1.4).
Supports macOS 13+, Apple Silicon (`arm64`) and Intel (`x86_64`). The four assets
are `Pulse-0.1.4.dmg`, `Pulse-0.1.4.dmg.sha256`, `Pulse-0.1.4.zip` and
`Pulse-0.1.4.zip.sha256`; DMG, updater ZIP and local installation contain the
same signed app.

Existing Pulse 0.1.3 installations can discover this release through
Settings → Updates or automatic checks. Manual installation: quit the previous
instance, open the DMG, drag Pulse into Applications and launch it. Avoid
running an older development build simultaneously. Preferences and Keychain
items remain in place; task compatibility handling is described above.

This is an Apple Development-signed preview, not Developer ID-signed or
notarized. It retains the existing preview distribution channel.

## Validation and limits

- 175 automated tests passed with isolated task stores and synthetic providers;
  strict formatting and independent review passed.
- Twenty Aqua/Dark Aqua interaction renders and full Home integration reviewed.
  Native AppKit tests exercise the actual entry field's visible text and binding
  through Undo/Redo, inherited disabled state, marked-text submit gating, and
  actual scroll movement after returning from the task editor.
- The release pipeline runs the complete tests, universal Release build,
  signing, mounted-DMG and extracted-ZIP verification, checksum checks, local
  installation verification and published asset-digest checks.
- Physical desktop mouse and Chinese input-method candidate delivery were not
  verified because Computer Use selection repeatedly timed out. Unit/render
  checks do not certify those live interactions.
