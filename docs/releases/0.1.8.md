# Pulse 0.1.8 (build 12)

## Changes

- **A calmer, more colorful daily view.** The menu-bar panel now has a fixed
  400 × 520 surface, softer adaptive colors, clearer spacing, and recognizable
  provider cards. Existing currencies and complete balance values are retained.
- **Tags are easier to manage at any scale.** Todo stays pinned, overflow arrows
  reveal more lists, and the selected tag has a visible actions menu. Rename,
  remove, reorder, or search all tags from the panel or Settings. There is no
  artificial tag-count cap; removing a tag moves its saved tasks to Todo and
  protects affected unfinished drafts.
- **Settings has its own window.** General, AI services, Lists & tags, Updates,
  and About each have a clear destination. Connection forms open when needed;
  Save and verify and Disconnect state what each action does. Connection status
  reflects a real usage check, not just the existence of a stored key.
- **Motion follows the action.** Hover, press, selection, completion and page
  changes use distinct restrained timing. Outgoing page snapshots avoid keeping
  retired text editors alive; Reduce Motion removes movement and scale.
- **Drafts stay with you.** Task and settings input survives ordinary navigation
  and window closure. Automatic installation waits for closed windows, no dirty
  drafts and no pending writes. Explicit quit/restart checks before installing.
- **English and Simplified Chinese** follow the system language, including
  dynamic status, error messages, native menus and accessibility labels.

Task storage remains schema version 1. Preferences and existing Keychain items
stay in place. No new provider, telemetry, subscription or cloud sync is added.

## Installation and updates

Download [Pulse 0.1.8](https://github.com/zibochen6/Pulse/releases/tag/v0.1.8).
Supports macOS 13+, Apple Silicon (`arm64`) and Intel (`x86_64`). Assets:
`Pulse-0.1.8.dmg`, `Pulse-0.1.8.dmg.sha256`, `Pulse-0.1.8.zip`, and
`Pulse-0.1.8.zip.sha256`. The manual DMG, updater ZIP and local installation use
the same signed app. Existing 0.1.3+ installations can discover it through the
update settings or automatic checks.

This continues the Apple Development-signed preview channel; it is not
Developer ID-signed or notarized.

## Verification and limits

- 235 automated tests passed, with two opt-in demo tests skipped during the
  normal suite; 24 additional Chinese UI/localization/settings checks passed.
  Coverage includes 100 tags, native layout bounds, draft identity, connection
  truthfulness, window ownership, asynchronous reorder and installer preflight.
- Release build and strict formatting passed. Bilingual light/dark screenshots
  and 18-second demonstrations use actual product views with labelled synthetic
  accounts and tasks. See [the preview gallery](../media/ui-redesign/README.md).
- Native interaction confirmed Chinese tag rename/save, search and shared tag
  state in the independent Settings window.
- Real NSPopover hover timing, outside-drag/Escape cancellation and Chinese IME
  composition still need manual release acceptance. Tests ran on macOS 27.0.1;
  macOS 13 is the deployment target, not a claim of runtime testing on that OS.
- The release pipeline checks universal architecture, signing, both packaged
  payloads, checksums, installed executable identity and published asset digests.
