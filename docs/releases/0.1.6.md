# Pulse 0.1.6 (build 10)

## Changes

- **Reorder your tag tabs by dragging them.** Drag a custom tab left or right
  and drop it where it should live; the order is written to the task file and
  survives relaunch. While dragging, the tab dims and an accent caret marks the
  slot it will land in, so the result is visible before you let go. **Todo**
  stays fixed at the left and is never draggable.
- Reordering never depends on dragging: each tab's context menu offers
  **Move Left** / **Move Right** (⌥⌘← / ⌥⌘→), and Settings → Tasks has the same
  two moves. All three paths land the tag in exactly the same slot.
- A dropped order appears immediately and settles once it is saved. If the save
  fails, the bar returns to the saved order instead of keeping a preview that
  never landed. Moving a tab to its own slot does nothing and writes nothing.
- Refine motion and interaction detail across the task surface. Hover, press,
  selection, disclosure, insertion and reorder now each use one deliberate
  curve instead of several unrelated durations. Tabs acknowledge a press with a
  short scale-down, and keyboard focus draws a capsule-shaped soft affordance
  instead of the square system ring.
- Completion pops its check mark in rather than swapping glyphs, the
  **Completed** section's chevron rotates instead of changing symbol, and task
  rows, the inline composer, error banners and the deletion undo bar now
  transition in and out instead of appearing instantly.

Every new animation respects Reduce Motion; with it enabled, nothing moves and
behaves exactly as before. No storage schema change is introduced: task data,
preferences and Keychain items remain in place, and existing files need no
migration.

## Installation and updates

Download [Pulse 0.1.6](https://github.com/zibochen6/Pulse/releases/tag/v0.1.6).
Supports macOS 13+, Apple Silicon (`arm64`) and Intel (`x86_64`). Assets:
`Pulse-0.1.6.dmg`, `Pulse-0.1.6.dmg.sha256`, `Pulse-0.1.6.zip` and
`Pulse-0.1.6.zip.sha256`. DMG, updater ZIP and local installation use the same
signed application.

Existing Pulse 0.1.3 and later installations can discover this version through
Settings → Updates or automatic checks. For manual installation, quit Pulse,
open the DMG and drag Pulse into Applications before launching it again.

This remains an Apple Development-signed preview, not Developer ID-signed or
notarized, using the existing preview distribution channel.

## Validation and limits

- 204 automated tests passed using isolated task stores, including the pure
  drop-placement rules (both directions, both ends, and every ignored drop),
  tag reordering and its no-write no-op case, controller de-duplication of a
  repeated drag, optimistic preview and rollback, and the previous suite of
  focus, scroll, draft, repeat, undo and IME behavior.
- Strict formatting and diff checks passed. Thirty-two Aqua/Dark Aqua state
  renders were generated and inspected, including two new drag states showing
  the insertion caret and the dimmed dragged tab without clipping or overlap.
- The release pipeline verifies tests, universal build, signing, mounted DMG,
  extracted ZIP, checksums, installed application and published asset digests.
- Actual desktop mouse dragging remains unverified because native automation
  cannot drive this accessory application. Placement, persistence and the
  keyboard/menu equivalents are covered by tests, but only a real drag can
  confirm how it feels to use.
